
# 🖥️ DevWeb Conference
1° SEMESTRE | ENG. SOFTWARE PUC MINAS - (DESENVOLVIMENTO DE INTERFACES WEB)

## 🔍 Descrição

Projeto da 3ª aula prática de Git/GitHub na disciplina de Desenvolvimento de Interfaces Web (PUC Minas). O repositório demonstra o uso de versionamento com git e cria uma interface web simples de uma conferência de Desenvolvedores Web utilizando HTML e CSS.

## 📦 Tecnologias Utilizadas

## 🚀 Instalação

Clone o repositório:  

```bash
git clone https://github.com/odiasdev/devweb-conference.git
```

## ▶️ Executando o App

Basta abrir o arquivo `index.html` no navegador.
